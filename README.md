# Lego City Undercover Mouse Support


## Features

- Control the camera using your mouse
- Left & right click can be bound to keyboard buttons
- Adjustable sensiivity

## Installation

- Download latest release
- Extract contents into LEGO City Undercover installation folder (where LEGOLCUR_DX11.exe is located)
- Play!

## Usage

- Scroll adjust camera distance
- Home/End buttons increase/decrease sensitivity in game or adjust in ini file
- F8 enables/disables mouse-camera control. Set `togglekey` under `[settings]` in `lcu.ini` to another hexadecimal Windows virtual-key code (default `0x77`).
- F9 toggles between fullscreen and a normal decorated window. The windowed size is set to about 80% of the current monitor's work area; pressing F9 again restores the previous mode and placement.
- By default Left and right click are bound to Q + E. Edit the ini file to change these or adjust your in game mappings accordingly. Use virtual keycodes in ini https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes

## Recent Changes

- Added an F9 fullscreen/windowed toggle. Windowed mode uses a normal decorated window centered at about 80% of the monitor's work area; pressing F9 again restores the previous placement.
- The existing F8 mouse-camera toggle remains unchanged.
